# SAP Procure-to-Pay (P2P) Process – Capstone Project

## 📌 Project Overview

This project demonstrates the complete **Procure-to-Pay (P2P)** cycle in SAP using the **Materials Management (MM)** module integrated with **Financial Accounting (FI)**.
It covers the full procurement lifecycle from purchase requisition to vendor payment.

---

## 🎯 Objectives

* Configure organizational structure for a company (**ABC Pvt. Ltd.**)
* Execute end-to-end P2P process in SAP MM
* Integrate MM with FI (GR/IR clearing, vendor liability)
* Perform key transactions like PR, PO, GR, Invoice, and Payment
* Provide a practical implementation of SAP procurement workflow

---

## 🔄 P2P Process Flow

Purchase Requisition (ME51N) → Purchase Order (ME21N) → Goods Receipt (MIGO) → Invoice Verification (MIRO) → Payment (F-53 / F110)

---

## 🛠️ Tech Stack

* SAP MM (Materials Management)
* SAP FI (Financial Accounting)
